# Restore bounded range proofs for the owned-vector example

The owned-vector example must continue to verify after range byte counts carry
explicit forward-range and no-overflow obligations.

**Violated invariant.** Every symbolic element range used by a contract or
resource call must establish both that it is forward and that its byte extent
fits the 32-bit memory model. A caller must be able to transport those facts
through a callee whose contract mentions the same ranges.

**Regression** (`examples/owned-vector/vector.click`): the `example_projects`
gate fails while checking `vector_copy`/`vector_grow` because the symbolic
`length`, `dst_capacity`, and `src_capacity` ranges do not establish the
generated byte-bound guards at the call boundary.

**Acceptance criteria.**

- `examples/owned-vector` verifies under `scripts/check.sh` with the range
  byte-count checks enabled.
- The proof supplies the actual range bounds through explicit contracts,
  resources, or simple transport steps; it does not weaken or bypass the
  generated obligations.
- The full example and mdtest gates remain green.
